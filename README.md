# 活網仔小精靈

完整的動機、逐步接線、實測與後續規劃，請看 [里程碑作品紀錄](milestone.md)。

無聊的時候，找個姐妹亂聊一下。用 LINE 傳一句話，讓 n8n 接住，再由 AI 回覆。

我想要它講一個冷笑話、接一個諧音梗或爛梗，有點已讀亂回的感覺，但又有接到我在說什麼。也想讓它依照我今天想看的題材，幫我找一部 AI 短劇，直接給我連結。

![n8n 流程截圖](workflow.jpg)

## 目前的功能

- 冷笑話：一次一則，不用解釋笑點。
- 諧音梗／爛梗：照我給的詞接一個梗。
- AI 短劇：一次一部，依題材查找，附可核對的連結。排除只有劇情提到 AI 的真人劇。
- 冷知識：被問到時給一則有來源的內容。

說話方式是繁體中文、像姐妹聊天，短一點、自然一點，不要客服腔，也不要每次自我介紹或硬問我要不要更多。

## LINE 和 AI 怎麼接起來

LINE → Webhook → HTTP Request（等待提示）→ AI Agent → HTTP Request（回傳 LINE）

AI Agent 接 OpenAI Chat Model 與 Simple Memory；模型另設定 Web Search。記憶用 LINE userId 區分不同使用者。旁邊停用的 Message a model 是課程前一階段留下的節點，不在目前主流程內。

## 實際對話

以下保留測試時的回覆，移除姓名及帳號稱呼。

**我：** 講一個冷笑話  
**它：** 為什麼數學書很憂鬱？因為它有太多問題。

**我：** 拿珍珠奶茶接一個諧音爛梗  
**它：** 珍珠奶茶？「真煮奶茶」，喝了才知道是不是真心煮的。

**我：** 我想看復仇題材的 AI 短劇，或者現在熱門的。  
**它：** 推薦《拳拳AI意》，並附上紅果詳情連結。

第三輪有找到問題：官方頁面列出真人演員，故事中的「AI 偽裝角色」不代表作品是 AI 生成。因此這輪不能算 AI 短劇推薦成功。

## 我調整了什麼

一開始課程版叫小花，會放很多 Emoji，有時候還會寫詩。我覺得蠻生硬的，所以改成像姐妹聊天。短劇也改成一次一部、只找 AI 的。

測試發現，網址能開、劇名對得上，還不代表推薦就對了。我另外加上官方 AI 劇分類或 AI 劇榜的核對要求，明確排除《拳拳AI意》這種真人劇。也補強劇情不能亂編、查不到就明說，以及 LINE 只貼一次純網址的要求。

**目前驗證狀態：** LINE 收發、短期記憶、冷笑話及諧音梗已測試。AI 劇分類修正版已發布，仍待從 LINE 重測確認；換成無限流的測試也尚未完成。這份作品紀錄保留成功和失敗的結果，沒有把尚未驗證的功能當作完成。
